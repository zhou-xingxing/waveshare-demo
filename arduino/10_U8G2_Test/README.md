# 10_U8G2_Test —— 官方原版 Demo

ESP32-S3 + ST7305 300×400 反射屏的官方示例，**本仓库对它未作任何修改**。

它的用处是**验环境**：屏幕不亮、串口没输出、怀疑板子坏了的时候，拿它把
「硬件/环境有问题」和「我的代码写错了」分开 —— 官方代码都跑不起来，那就别怀疑自己。

## 依赖与配置

装环境（`arduino-cli` + ESP32 核心 + U8g2 库）和开发板配置都在
[仓库根目录的 README](../../README.md) 里，不在这里重复。
引脚同样是焊死的，完整表见根 README「硬件配置」。

## 屏幕上是什么

```
┌────────────────────────────────────────────┐
│                                            │
│                  12345                     │  ← 居中的大号帧计数
│            ST7305 refresh counter          │     （logisoso50 字体）
│                                            │
│ ────────────────────────────────────────── │
│ FPS:79.00  frame:12ms  flush:9ms           │  ← 底部：帧率 / 单帧耗时 / 刷屏耗时
└────────────────────────────────────────────┘
```

串口（115200）同步打印同样的数值，每行一条：

```
ST7305 U8g2 counter demo started
counter=1234 fps=79.00 frame=12 us flush=9 us
```

## 烧录

```bash
cd ..                                # 到仓库根目录
./build.sh flash 10_U8G2_Test
./build.sh mon                       # 115200
```

也可以不传 Demo 名（它就是默认 Demo）：`./build.sh flash`。
